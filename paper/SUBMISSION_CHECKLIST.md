# Computer Standards & Interfaces Submission Checklist

- `Ready`: Manuscript PDF: `elsarticle-template-num.pdf`
- `Ready`: Cover letter PDF: `cover.pdf`
- `Ready`: Highlights file: `csi-highlights.txt`
- `Ready`: Graphical abstract files: `figures/graphical_abstract.pdf` and preview `figures/graphical_abstract.png`
- `Ready`: Funding statement in manuscript
- `Ready`: Conflict of interest statement in manuscript
- `Ready`: Generative AI declaration in manuscript
- `Ready`: Figures referenced in manuscript are available as local files in the submission workspace
- `Ready`: Validator logs are present under `ai_risk/out/logs/`
- `Ready`: Reproduced `demo`, `real_smoke`, and `real` artifact outputs are present under `ai_risk/out/`
- `Manual`: Upload the competing-interest declaration document generated from Elsevier's declarations tool
- `Manual`: Confirm all author metadata in Editorial Manager exactly matches the manuscript
- `Manual`: Upload supplementary artifact files intended for readers from `ai_risk/out/logs/`, `ai_risk/out/real_smoke/`, and `ai_risk/out/real/`
- `Manual`: Verify whether a public artifact DOI will be added now or only after acceptance
- `Manual`: Keep the repository/data statement consistent with third-party CICIoT2023 and locally provisioned NVD/CVSS records

## Notes

- All submission-facing files should consistently target `Computer Standards & Interfaces`.
- The cover letter, manuscript title, and Editorial Manager metadata should use the same article title.
- The current CSI guide states that the journal uses a `single anonymized` review process.
- Keep the highlights as a separate editable plain-text file for upload.
- Upload the graphical abstract as a separate file in the submission system.
